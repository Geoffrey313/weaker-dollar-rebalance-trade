# Can a Weaker Dollar Rebalance Trade?

*Dominant-Currency Pricing and the Limits of the Mar-a-Lago Strategy in a Two-Country Model*

**Authors.** Geoffrey Ducournau · Junlin Li · Jallal (Qatar University).

This repository reproduces the empirical results of the paper. The manuscripts, the
generated results, and the data-acquisition code are kept in the working tree but are not
published here (see the data policy below).

## Abstract

The paper studies the limits of the exchange-rate channel as a tool for trade rebalancing.
Under dominant-currency pricing, a controlled Chinese capital account, and safe-asset
recycling, an engineered dollar depreciation does not deliver the textbook expenditure
switching. A two-country New Open Economy Macro model with dominant-currency pricing,
incomplete markets, and a capital-controls wedge is combined with firm-level and
product/sector evidence around the 2018-2019 tariff waves (2025 as an external test).

## Research questions

1. Through what channels does a bilateral tariff shock transmit to trade flows (U.S. import
   prices, foreign-side margins, traded quantities)?
2. Can a tariffs-as-leverage strategy for a coordinated dollar depreciation rebalance trade
   in a two-country model, or do structural frictions neutralise it?
3. Is there an exchange-rate trajectory that minimises the bilateral imbalance at bounded
   output-gap cost, and is it attainable given the frictions?
4. Do firms differentially exposed to Chinese inputs show different price, margin, and
   quantity responses around the tariff waves?

## Hypotheses

- **H1** High tariff pass-through to U.S. prices, muted quantity response under DCP.
- **H2** Frictions (dollar invoicing, closed capital account) block FX-based rebalancing.
- **H3** Rebalancing becomes attainable only above a threshold of RMB internationalisation.
- **H4** Firm-level incidence pattern (China-input exposure).
- **H5** Safe-asset feedback (extension only).

## Repository layout

```
src/
  common/    shared constants, config, portable paths
  data/      loading and reading the shipped transformed data
  engine/    the structural model (calibration, solution, counterfactuals)
  analysis/  the panels and event studies that produce the results
  figures/   figure and table scripts (EN and FR)
data/        transformed input data (see data/README.md) + data policy
reproduce.py single deterministic entry point
```

## Reproduction

```
python -m pip install -r requirements.txt
cp .env.example .env.local   # fill in credentials (never committed)
python reproduce.py
```

## Data policy

The firm-level and market data come from WRDS (Compustat, CRSP). **WRDS/Compustat data is
licensed and not redistributable**, so it is not versioned here; `data/README.md` documents
the schema and the data is available on request. The input-output tables (OECD ICIO, WIOD),
tariff calendars (Bown/PIIE, USITC), import prices (BLS), trade flows (Census/BEA), and
exchange rates (FRED/BIS/IMF) are public.
